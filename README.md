# Squeek DJ

A rhythm game where a real hamster sets the tempo. Squeek DJ reads Squeektoshi's live wheel RPM from the public Squeekchain API (https://api.squeekchain.com/v1/status) and turns it into the beat of a four-lane rhythm game: when the hamster sprints the track speeds up, when he naps the set ends. Includes a clearly labelled practice mode for when the wheel is still. Static single-page site — no wallet, no tokens, no backend.

Live: https://squeekdj.is-a.dev/
